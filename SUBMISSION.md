# STARTS Forward — STARTS Bridge

## Description

STARTS Bridge helps a public-health coalition turn a community priority into a shared implementation project and supervised, paid early-career role concepts. It uses the selected priority and existing initiatives to connect community interventions with a receiving service partner. The user reviews a concrete charter before saving it and can retrieve the same record after refresh.

## Reuse and original work

Inherited from CopilotKit's Agents, Everywhere starter: Next.js/React app, CopilotKit runtime and model adapter, Ambiguous MCP adapter, approval/session/origin controls and tests.

New prototype work: STARTS Forward interface; four synthetic public-health priorities; nine coordinated capabilities; global team matching; evidence studio; influence ladder; paid micro-projects and career pathways; impact tracking; official SDG/AI governance source summaries; domain prompt and tools; persistent local demo adapter and domain tests. See STARTS-FORWARD-README.md for checks and limitations.

## Two-minute demo outline

- 0:00–0:20: Explain the gap between community needs, separate initiatives and early-career employment.
- 0:20–0:45: Select a priority; show collaboration, paid-role concepts and SDG mappings.
- 0:45–1:20: Prepare a charter, inspect responsibilities, funding uncertainties and service handoff, then approve the local save.
- 1:20–1:40: Refresh and show the same saved record ID.
- 1:40–2:00: Show the official source library and state demo limitations and next live integration steps.
